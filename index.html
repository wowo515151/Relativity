Explore spacetime

Change a parameter and see how coordinates, intervals, and measured quantities relate between inertial frames. All values are synthetic illustrations.

CPU Float64 calculations are active. GPU initialization is optional.

How to use the lab

Each panel uses the same convention: c = 1 light-year per year for display, with spacetime intervals in normalized units. The library API uses SI units unless the caller supplies a consistent unit. Display coordinates never feed back into calculations.

GPU batching is optional. If WebGPU is unavailable, the CPU calculation path remains active.

Relativity Lab is an educational model, not experimental data. Numerical values are generated locally.
